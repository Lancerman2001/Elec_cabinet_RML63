# Selector CJK

Subset derived from Noto Sans CJK SC Regular, using the interface catalogue and ASCII characters. The modified family is named Selector CJK. Source: https://github.com/notofonts/noto-cjk . Copyright records from the source font are preserved in SelectorCJK.otf; see OFL.txt for the SIL Open Font License 1.1.

The font is a packaged application resource; it is not installed into the user's system font directories. Rebuild it with scripts/generate_font.py if new UI strings are added.
